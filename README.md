High Value Sales Aggregator

Project Overview

High Value Sales Aggregator is a Python-based mini project designed to analyze sales transactions, identify high-value customers, and provide useful business insights through an interactive dashboard.

Objectives

- Analyze customer purchase behavior.
- Identify high-value customers.
- Monitor revenue and sales performance.
- Display transaction records.
- Generate useful business insights.

Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Matplotlib / Data Visualization

Main Features

1. Revenue Analytics
2. Customer Segmentation
3. Live Deal Scorer
4. Transaction Ledger
5. CSV Data Aggregation
6. Add New Records

Installation and Execution

1. Clone the repository:

git clone https://github.com/supreeti1/High_Value_Sales_Aggregator.git

2. Open the project folder:

cd High_Value_Sales_Aggregator

3. Install the required libraries:

pip install -r requirements.txt

4. Run the application:

streamlit run app.py

Conclusion

This project demonstrates how Python and machine learning techniques can be used to analyze sales data, identify valuable customers, and support data-driven business decisions.
